cd ~/Desktop/ika && rm -rf build install log

🛠️ 1. DERLEME (BUILD & SOURCE - Her kod değişiminde ŞART)
cd ~/Desktop/ika
colcon build --packages-select ika_main
source install/setup.bash
cd ~/Desktop/ika && colcon build --packages-select ika_main && source install/setup.bash
🌍 2. SİMÜLASYONU AÇ (GAZEBO ve ROBOTU YÜKLE)
ros2 launch ika_main sim.launch.py

👀 3. SENSÖR İŞLEME (3D'den 2D'ye Asfalt Filtresi)
(Yeni terminalde)
ros2 run ika_main sensor_isleme

🧠 4. OTONOM SÜRÜŞ (PID Karar Mekanizması)
(Yeni terminalde. Not: Eğer setup.py dosyasında adını otonom_surucu yaptıysan öyle çalıştır)

⚙️ 5. ANA KONTROL (Beyin - Motorlara İzin Ver)
(Yeni terminalde. DİKKAT: Bu çalışmadan araç ASLA hareket etmez!)

🕹️ 6. MANUEL KONTROL (TELEOP - Acil Durum / Test İçin)
(Yeni terminalde)
